Theme lab

Two levels. Palette: the raw colours (picker or HSL + alpha), shared by every theme; the number is how many tokens use each one. Themes: each token points to a palette colour, optionally at a % (opacity); its swatch picks a colour without touching the palette: an existing palette colour is used as is, otherwise you can use the closest one or add a new step (grey-750). ↺ resets a changed row. Changes show live below and are kept in this browser until the stylesheet has them: export them to _themes.scss, or import that file here.
